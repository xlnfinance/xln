01 · Why it exists

Hide a seed forever.
Still find it when it matters.

Found.The finder has the key.

Lost.You no longer have the key.

A random seed is cryptographically strong. The copy is the problem: whoever finds it owns the wallet; lose it and the wallet is gone. Classic brainwallets removed the copy, but let attackers guess at full speed. BrainVault makes each guess expensive.

02 · One public recipe

Remember. Work. Recover.

  1. 01

    Exact inputs

    Username, password, shard count, multiplier. Case and spaces matter.

  2. 02

    Memory-hard work

    Each Argon2id job uses 256 MiB. Standard runs 10,000.

  3. 03

    Same wallet

    BLAKE3 creates one root, then two separate BIP-39 wallets.

CPU, GPU, and worker count change only the wait—never the wallet. Import either wallet with an empty BIP-39 passphrase.

Maximum paranoia: verify the package yourself

Prebuilt binaries are hash-checked before execution. verify:source rebuilds every Apple binary twice from vendored source and requires identical bytes.

mkdir brainvault-audit && cd brainvault-audit
bun init -y
bun add --exact --ignore-scripts brainvault@2.2.0
cd node_modules/brainvault
bun run verify:source
bun run check
bun run test:matrix
