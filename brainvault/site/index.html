01 · Why it exists

A seed is safe only while it is both hidden and found.

Found.The finder has the key.

Lost.You no longer have the key.

A random mnemonic has excellent entropy, but its words become a physical bearer secret you must protect for life. Old brainwallets removed the paper and made password guessing cheap. BrainVault keeps recovery from memory while making every candidate expensive.

02 · One public recipe

Remember. Work. Recover.

  1. 01

    Exact inputs

    Username, password, shard count, and multiplier. One changed character opens a different wallet.

  2. 02

    Memory-hard work

    Standard runs 10,000 numbered Argon2id jobs. An attacker repeats all of them for every candidate.

  3. 03

    Standard output

    An ordered BLAKE3 fold creates one root, then two separate BIP-39 wallets.

Faster hardware changes only the wait—never the wallet. Import either wallet with an empty optional BIP-39 passphrase.

14.379 s

10,000 shards, measured.Production run on an Apple M3 Ultra: 32 CPU cores, 80 GPU cores, 512 GiB unified memory; 8,000 Metal + 2,000 C/NEON shards. Laptop time varies.

Maximum paranoia: verify the package yourself

The package uses hash-verified prebuilt binaries. This path installs without scripts, rebuilds every Apple native artifact twice from vendored source, and requires byte-for-byte equality.

mkdir brainvault-audit && cd brainvault-audit
bun init -y
bun add --exact --ignore-scripts brainvault@2.2.0
cd node_modules/brainvault
bun run verify:source
bun run check
bun run test:matrix
bun ./brainvault --smoke --workers 32
