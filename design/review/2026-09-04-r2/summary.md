## Priority fixes by reviewer

### openrouter/google/gemini-flash-latest · desktop-dark · 719

The desktop dark interface establishes an exceptionally calm, high-trust fintech aesthetic with disciplined typography, subtle card surfaces, and robust cryptographic verification cues. However, it suffers from severe desktop viewport underutilization where mobile single columns float in vast black space, lingering toast notifications leak across screens, and the core 'visceral value' one-scale bar principle is frequently abandoned or obscured.

- Enforce responsive two-column desktop layouts on Receive, Swap, Account, and Settings to eliminate single-column mobile containers stranded in 60%+ empty canvas.
- Fix notification lifecycle and state bugs: dismiss the sticky 'Payment submitted' toast on navigation, harmonize receipt modal with activity detail (same frame #40 and timing), and remove the orphan 'just now' text artifact.
- Implement true visceral value scale across all screens: draw bars strictly at Settings 1 px = $N without stretching to card widths or gradient fading, add a minimum readable delta indicator with zoom for small payments, and add magnitude bars to Activity rows.
- Complete the Swap engine experience: display live exchange rates, slippage, and estimated output for token pairs, and show dual capacity bars for both sold and received tokens in the right rail.
- Clean data legibility and contrast: distinguish the duplicate 'Credit limit updated' rows as 'Your credit line' vs 'Their credit line', brighten capacity captions under bilateral bars to #A1A1AA, and soften the glaring white QR card.

### openrouter/google/gemini-flash-latest · desktop-light · 786

The light desktop variant delivers crisp typography, strong bilateral balance visualization, and exemplary cryptographic provability cues. However, several screens suffer from narrow single-column mobile layouts stretched across desktop width alongside lingering toast notifications and stray text artifacts.

- Auto-dismiss bottom transaction toasts upon receipt modal display and clear notification state across route changes (affects 03-receipt, 04-receive, 05-swap, 06-account).
- Convert single-column desktop layouts on Receive (04), Account (06), and Settings (09) into balanced two-column grids utilizing the full desktop canvas.
- Clean visual rendering bugs: eliminate the orphan dot in Pay amount (02) and the stray uncontained 'just now' string in Activity detail (08).
- Standardize address formatting to middle-ellipsis truncation with copy icons across 'To' inputs (02), Receive entity IDs (04), and Runtime IDs (09).
- Introduce quote/exchange rate disclosures in Swap (05) and replace the right-edge gradient fade on the Total balance bar (01) with a strict scale overflow indicator.

### openrouter/google/gemini-flash-latest · mobile-dark · 631

The mobile dark interface delivers strong native ergonomic foundations with clear dark surfaces, legible tabular typography, and provable runtime cryptographic primitives. However, visceral value is almost completely unrealized due to full-width bar stretching that ignores the global scale, while persistent toast leakage, off-by-one frame discrepancies (#42 vs #43), and bottom-sheet layout collisions erode fintech-grade polish and trust.

- Enforce the global 1px = $N scale strictly across all horizontal bars on Home, Pay, Receive, and Account: replace width: 100% with container clipping, directional gradient fades, and numeric remainder chips so visual lengths represent real proportional value.
- Fix the asynchronous toast leak and decouple settlement receipts: dismiss or suppress Payment submitted toasts on frame commitment, prevent cross-screen toast bleed (seen on Receive and Swap), and eliminate conflicting optimistic messaging on committed modals.
- Resolve the deterministic frame counter discrepancy between screens: ensure the payment receipt sheet (currently #42) and the activity ledger detail (currently #43) display the identical committed frame index and include full proof hashes on both.
- Add proper safe-area and bottom navigation scroll clearance (padding-bottom: 96px) across scrollable views to eliminate the severe overlap of fixed bottom tabs over the Settings runtime section and Activity filters.
- Disambiguate credit limit updates in Activity and Home feeds by labeling directionality explicitly (Their credit line vs Your credit line), and add complete quote execution mechanics (exchange rate, provider, network fee) to the Swap screen.

### openrouter/x-ai/grok-latest · desktop-dark · 599

The dark desktop shell is calm and the right shape — rail, hero total, Pay two-column, Activity master-detail — but it is not yet a shipping wallet: money bars stretch to the card instead of the promised 1px=$N scale, Receive/Account/Swap are centered mobile columns, and a leftover 'Payment submitted' toast contradicts the PAID receipt. Until bars are comparable and the paid state is singular, the product’s own differentiators (visceral value, provable instant settlement) do not show up on screen.

- Honor Settings 1px=$N on every money bar (Home USDC, Hub One send/receive, Pay Before/After, Activity rows); compose the send half from credit line + collateral + owed; clip overflow instead of filling the card; delete the Receive 0.00 gradient.
- One payment state: dismiss 'Payment submitted: 25.00 USDC to Meridian Desk' as soon as PAID is shown — Receipt, Receive, Swap, Account, Activity (07) all still carry it.
- Give Receive, Account, and Swap real two-column desktop layouts (QR|share, position|ledger, pair|quote); stop parking a ~420px mobile stack on the canvas.
- Pay: one route (right graph), one fee with hop math, one account viz (Before/After); drop in-form chips, the duplicate bar, and the sandbox badge on You.
- Receipt (03) and Activity detail (08): one frame id, one timestamp, copyable proof, one verb (Paid/Settled) — not #40 vs #41, 2038 ms vs 00:27:30 vs submitted.
