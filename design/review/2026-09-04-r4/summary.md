## Priority fixes by reviewer

### openrouter/x-ai/grok-latest · desktop-light · 704

Light desktop is a competent two-column fintech shell with real proof cues (frames, runtime verify, bilateral bars), but it is not yet premium: Home/Pay repeat numbers and legends, Swap is an empty quote, and Activity abandons the one-scale bar. Light theme contrast is mostly fine, yet indigo CTAs, chips, and outlined cards add noise that Revolut/Cash App would delete.

- Enforce one absolute bar scale on Home total, Home USDC, Account, Pay, Receive, and Activity amounts; fade overflow instead of compressing $11.5k next to a 100k credit bar.
- Kill repeating chrome: Home tier legend, Pay duplicate Hub One bars, Account color legend, Settings’ triple 1px=$50, five Activity chips.
- One primary CTA per screen (Pay); demote Receive/Swap/Extend credit so desktop does not look like three equal app-store buttons.
- Finish Swap: live You receive quote and a non-disabled primary, and fill the right column instead of leaving half the canvas blank.
- Make receipts/activity inspectable: latency vs timestamp split, copyable proof, and a 25px debit mark so $25 is viscerally small against $10k.

### openrouter/google/gemini-flash-latest · desktop-dark · 839

The design achieves an elite, disciplined fintech aesthetic with authoritative typography, restraint in accent color, and an innovative absolute-scale visceral bar concept. Its primary weakness is responsive desktop spatial composition: generous vertical whitespace turns into empty dead voids on wider viewports across almost every secondary flow.

- Constrain desktop layout max-width or balance two-column modules to eliminate dead empty space across the lower halves of Home, Receive, Swap, and Activity.
- Add a min-width (2px) and active state indicator for low-dollar entries on the visceral bar in Pay and Home so small transactions remain perceptible at $50/px.
- Redesign the Receive screen QR code surface to eliminate dark-mode glare and harmonize its container styling with the rest of the dark card system.
- Refactor visceral bar legends across Home, Pay, and Account from passive plain text into structured, data-dense metric captions directly bound to the bar segments.
- Establish active selection states on Activity feed items and provide concrete cryptographic proof actions (copy frame proof, inspect signature) on transaction detail cards.

### openrouter/google/gemini-flash-latest · mobile-dark · 839

A remarkably disciplined, high-conviction fintech wallet interface with exceptional typography, state transparency, and dark-theme restraint. It falters primarily where secondary text blocks and hex strings clutter the viewport and where the signature 'visceral value' bar principle is omitted on Swap, Activity, and Receipt sheets.

- Bring the visceral value bar principle to Swap, Activity rows, and Receipt sheets so scale parity is truly universal across all money states.
- Unify the post-payment receipt sheet (03) and activity detail sheet (08) into a single canonical component with consistent verification badges and checkmarks.
- Move the 'AT THIS SCALE' calibration preview in Settings right below the scale slider instead of burying it beneath Runtime and Vault rows.
- Format and truncate raw 0x hex strings across Pay, Receive, and Settings to eliminate multi-line unformatted monospace wraps.
- Consolidate total balance legend bullets and receive copy actions on Home and Receive to eliminate nested card fatigue and tighten thumb-zone ergonomics.

### zai-coding-cn/glm-4.6v · mobile-dark · 855

The mobile dark variant demonstrates strong execution of the visceral value concept and maintains excellent consistency across screens. The premium dark aesthetic is largely successful though some text elements lack sufficient contrast and hierarchy. The responsive design effectively adapts to mobile constraints while preserving the core visual language.

- Increase text contrast and size for better readability
- Refine the home screen hierarchy and remove redundant elements
- Improve visual feedback for interactive elements
- Simplify technical language in settings
- Enhance the swap screen user experience and clarity

The one-scale bar is explained in Settings and contradicted everywhere else by shortened Home bars, absent Activity/Swap marks, and Receive’s fake fade.

- Delete redundant legends/chips (Home tier list, hub chip, Pay Arrives/Delivery, Receive triple copy, Account four-key legend vs two-tone bar).

However, it suffers from verbose descriptive copy, cluttered pill clusters, and nested card borders that make the light canvas feel visually noisy compared to a top-tier fintech app.

- Prune helper text and unformatted 84-character hex addresses across all screens to single-line truncated monospaced chips with tap-to-copy.
- Remove nested card wrappers in favor of flat canvas rows with 0.5px dividers to eliminate card-in-card claustrophobia.
- Enforce minimum visual width (3px) and rounded endpoints on low-value visceral scale bars so small amounts ($25) do not render as single-pixel artifacts.
- Clean up the Home screen legend and action cluster by replacing multi-line wrapped text and colored dot legends with clean tabular rows.
- Fix mobile spacing and bottom scroll padding across all views to prevent text and CTA collisions with the fixed bottom tab navigation bar.
