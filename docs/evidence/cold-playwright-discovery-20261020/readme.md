# Cold Playwright discovery

The exact unit command could time out while listing real Cross tests with a cold transform cache. Discovery now waits for the independent root and React package lists concurrently and retains their deterministic order. Both CLI children must finish before an error is returned. Execution-only test imports load through the existing CommonJS transform before their financial validation or UI effects.

The original five-second regression now creates its own empty cache. The focused cohort passed 67/67 with 1,052 assertions; the cold case took 3,734.95 ms. The real MM full/partial-fill browser case passed with strict browser health in 32.5 seconds (131.97 seconds including the isolated stand). No financial assertion or timeout was relaxed.

[Evidence](proof.json) preserves the original failure, the rejected lazy-ESM attempt, the exact rerun and the child-lifecycle counterexample. These focused results do not replace final committed-SHA unit, financial, release, browser or soak acceptance.
